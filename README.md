# Adarsh Jha 3D Portfolio

An interactive portfolio for Adarsh Jha, a Computer Science undergraduate interested in software engineering, cloud, data/AI and cybersecurity.

The site preserves a React + Vite, Three.js, React Three Fiber, Drei, Spline, GSAP and Framer Motion experience with responsive navigation, 3D scenes, particles, an interactive skill keyboard and project exploration.

## Run locally

```bash
npm install
npm run dev
```

Build for production with:

```bash
npm run build
npm run preview
```

## Sections

- About
- Skills with an interactive Spline keyboard
- Projects with source links and verified live demos where available
- Achievements and certifications
- Contact form ready for personal EmailJS configuration
